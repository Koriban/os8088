# KBDFSX on the Satellite 4025CDT — four runs, 2026-10-21

The raw transcripts behind docs/FIELD-NOTES.md 68: "the keyboard stops after a
full-screen app, the mouse does not". Written by `tests/kbdfsx` on the owner's
machine and read off the CF card; kept because the entry's six eliminations
rest on them and a summary is not evidence.

Machine: Toshiba Satellite 4025CDT, VBE 1024x768 desktop, PS/2 keyboard AND
PS/2 mouse. Card: a current-tree `make cfimg CFGEOM=194/255/63` build.

**Read the columns, not the prose:** `21` bit 1 is IRQ1's mask, `A1` bit 4 is
IRQ12's, `head`/`tail` are 40:1A/40:1C, `i09`/`i74` are the two gates, `keys`
is what the package itself received. Across all four runs `21` is `00B8`,
`i09` is `0060:351C`, `i74` is `0060:32EB`, and the 8042 command byte is
`0047`. The fault never appeared.

Runs 1 and 2 are KBDFSX's own brackets. Run 3 ran Cyclone and DrMarco
WINDOWED first (neither enters full screen on its own - Cyclone wants `F`,
DrMarco wants a game started). Run 4 ran both of them FULL SCREEN first, which
is the one that matters.

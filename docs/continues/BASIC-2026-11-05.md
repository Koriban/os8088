## In progress: wave 3a, strings

**Uncommitted at the time of writing** — `SPEC.md`, `apps/basic/basic.asm`,
`apps/basic/baslang.inc`, `tests/basiclang.py`, `tests/os88qemu.py`.

§126.28 is the contract and it is written. A string value is a **(DS offset,
length) pair**, four bytes, inside the eight the variable table already has.
The type is the name's spelling, so nothing on the value stack carries a tag.
The arena is 4,096 bytes **in the package's own bss**, in two regions growing
towards each other: variables up from the bottom, temporaries down from the
top and released whole at every `OP_LINE`.

Working on the glass: literals, `a$`, assignment (which copies), `+`, `PRINT`
of either kind, and all six relations from one `OP_SCMP` plus a numeric
compare against zero.

**The three defects this cost are all one blind spot** and are worth reading
before touching the arena: *an allocation is a thing that can move your
operand.* A read takes a copy for that reason; the copy's source offset must
be read **after** the allocation, not before; and a zero-length string owns
no bytes, so compaction must skip it or it is chosen forever and the package
hangs. The 200-iteration `c$ = "y" + c$` in `PART18` is what forces the
arena to fill and is the most valuable line in the part.

## How it is verified

Two soak rows out of one file, because the whole set is too slow to iterate
against and holds one soak slot while others idle:

```
python3 tests/basiclang.py --early     # the language through SELECT
python3 tests/basiclang.py --late      # GOTO, labels, procedures, strings
python3 tools/os88test.py soak -k 'basiclang*'
```

The row reads the console **buffer** out of guest memory rather than the
pixels, anchored on a sentinel each part prints; a part that tests a
compile-time refusal prints nothing at all, so those read the address an
earlier part found. Expectations are in **execution** order, so a
procedure's output is owed by the line that CALLS it, and one line may be
owed several. Each part waits for its own last answer rather than a fixed
clock.

`tests/unit/t_fpscratch.py` and `tests/unit/t_basrefuse.py` are the fast-tier
guards; the second holds that a refusal helper which is ever `call`ed is
never `jmp`ed to, and its docstring explains why the stronger check is not
sound.
